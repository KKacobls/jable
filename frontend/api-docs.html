程式串接教學

任務列表圖片圖庫 壓縮設定API 串接

架構

前端 frontend/ 是 HTML、CSS、JavaScript 靜態網站。後端 backend/api.py 提供 JSON API，不依賴 Jinja。預設都從 6003 埠提供，Cloudflare Tunnel 只需要指向 http://127.0.0.1:6003。

新增任務

POST /api/download，JSON Content-Type: application/json：

{"name":"demo-001","hls_url":"https://example.com/video.m3u8","image_url":""}

HTTP 201 = 已排入佇列；HTTP 200 + added:false = 已有紀錄，不重複下載；HTTP 422 = 格式錯誤。也接受 {"video_text":"六行貼上格式"}。

任務與設定 API

GET /api/tasks：全部狀態；GET /api/tasks/demo-001：單筆。

POST /api/retry/demo-001：重試；POST /api/retry/errors：重試全部錯誤。

GET /api/settings、PUT /api/settings：讀取／更新設定；GET /api/health：健康檢查。

手動壓縮（不重新下載）

POST /api/tasks/demo-001/compression/start：將本機未壓縮 MP4 送入 H.265 佇列，不會連線到原 M3U8。

如果本機只有 TS，且沒有快取 M3U8，第一次呼叫會回傳 409、needs_segment_confirmation: true 與 available_segments。確認分段數後才能再次送出，例如：

{"confirm_segments":1817,"delete_ts_after_merge":false}

注意：分段數量連續不代表整部影片完整；預設保留來源 TS。若要清除 TS，必須確認分段總數並明確傳送 delete_ts_after_merge:true。本機有完整 MP4 時無需傳任何參數。

雙進度與壓縮暫停

任務欄位：download_current、download_total、compression_percent、compression_state。

POST /api/tasks/demo-001/compression/pause：暫停正在執行的壓縮。

POST /api/tasks/demo-001/compression/resume：繼續同一個 FFmpeg 處理程序。

DELETE /api/tasks/demo-001，JSON：{"confirm":"demo-001"}：將任務與資料移入垃圾桶。伺服器重啟後暫停狀態不能續接。

Python 範例

import requests
BASE = "http://127.0.0.1:6003"
r = requests.post(BASE + "/api/download", json={
    "name": "demo-001",
    "hls_url": "https://example.com/video.m3u8",
    "image_url": ""
}, timeout=15)
print(r.status_code, r.json())
print(requests.get(BASE + "/api/tasks/demo-001", timeout=15).json())

權限說明

依需求不使用密碼或登入，也沒有訪客 IP 白名單。知道服務網址的任何人都可以呼叫這些 API；若你公開 Cloudflare 網域，訪客也能修改下載任務與設定。
